## Pourquoi il n'y a pas encore d'autres candidats ici
- la recherche officielle large (communes, préfectures, régions, parcs) déclenche rapidement des protections anti-bot côté moteurs
- pour les textes potentiellement nouveaux, il faut confirmer qu'ils concernent bien le canyonisme et pas un autre usage du site
- le risque de faux positif est élevé sans lecture humaine du texte source

## Règle d'ajout pour les prochains candidats
Un texte ne doit être ajouté ici que si les éléments suivants sont disponibles :
1. **titre exact**
2. **source officielle directe** (`gouv.fr`, site communal, parc, etc.)
3. **date identifiable**
4. **territoire / canyons concernés**
5. **niveau de confiance** (`élevé`, `moyen`, `faible`)
